# 🤖 JARVIS - Voice-Based Data Analytics Assistant

JARVIS is a voice-based data analytics assistant that allows users to interact with retail sales data using natural voice commands.

## 📌 Project Overview

JARVIS combines voice interaction with data analytics and interactive visualization. Users can ask questions about sales data and receive answers through voice responses.

The project also provides a Streamlit dashboard with interactive Plotly charts.

## 🚀 Features

- 🎤 Voice-based interaction
- 🔊 Voice responses
- 💰 Total sales analysis
- 📊 Average, minimum, and maximum sales
- 📦 Total quantity sold
- 🏆 Highest and lowest sales by region
- 📅 Highest and lowest sales by month
- 📈 Sales distribution visualization
- 🌎 Sales by region visualization
- 📅 Sales by month visualization
- 📊 Display all charts through voice commands

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- SpeechRecognition
- PyAudio
- pyttsx3
